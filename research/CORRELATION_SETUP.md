# Setting Up Correlation Analysis

The `correlation.py` script compares human fluency ratings with your automated fluency scores.

## Requirements

### 1. Human Fluency Ratings File

You need to create a CSV file with human fluency ratings:

**File location**: `/human_fluency_ratings_aggregated.csv` (in project root)

**Required columns**:

- `sample_id` (int): Sample number (1-29 for S01-S30)
- `human_fluency` (float): Mean human fluency rating (0-100 or 1-9 scale, depending on your ratings)

**Example format**:

```csv
sample_id,human_fluency
1,72.5
2,68.0
3,61.5
4,37.0
5,29.5
...
29,53.0
30,55.0
```

### 2. Automated Scores CSV

This is automatically generated by `batch_scorer.py`:

- Location: `/results/batch_scoring_{YYYY-MM-DD}_{counter}.csv`
- The script automatically loads the latest scoring CSV

## Running the Correlation Analysis

Once you have the human ratings file in place:

```bash
cd research
python corelation.py
```

Or using uv:

```bash
cd research
uv run corelation.py
```

## Output

The script will:

1. Load human and automated fluency scores
2. Merge them on sample_id
3. Calculate Spearman correlations between:
   - Auto score (0-100) vs human ratings
   - Auto band (1-9) vs human ratings
4. Perform bootstrap analysis (5000 iterations) to estimate:
   - Difference between correlations
   - 95% confidence intervals

Example output:

```
Loading auto scores from: batch_scoring_2026-02-08_001.csv
Successfully merged 29 records

Spearman correlations:
Auto fluency score (0-100) vs human:  ρ = 0.756, p = 0.0001
Auto fluency band (1-9) vs human:     ρ = 0.754, p = 0.0001

Difference in correlation (score − band):
Mean diff = 0.002
95% CI = [-0.085, 0.089]
```

## Notes

- The script converts file names (S01-S30) to sample IDs (1-30) automatically
- It uses Spearman's rank correlation (non-parametric, robust to outliers)
- Bootstrap resampling provides confidence intervals for correlation differences
- All 29 samples must have both human and auto scores for analysis
